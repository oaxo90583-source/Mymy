# บอทคำนวณมวยพักยก — คู่มือใช้งาน (ภาษาไทย)

บอท LINE สำหรับจัดการมวยพักยกแบบครบวงจร: เปิดราคาจากคีย์ลัด, รับยอดแทงจากสมาชิก, คำนวณอัตราจ่ายตามเรทจริง, ตรวจเครดิตและป้ายรับ, ฝาก-ถอน-เติมเงิน, ประกาศผลและสรุปบิล, พร้อมพอร์ทแอดมินแบบเว็บสำหรับดูยอดรวมเจ้ามือและแก้ไขคีย์ลัดทั้ง 206 รายการ

## โครงสร้างโปรเจกต์

```
muaythai_bot/
├── app/
│   ├── calc.py        เครื่องคำนวณหลัก: แปลงข้อความราคา (ด52, ง31, ด10/9, รองเงิน, กลางอากาศ, คู่ดับเบิ้ล)
│   ├── bot.py         หัวใจของบอท: ตีความข้อความ → ตอบกลับ (แทง/เครดิต/ผล/คีย์ลัด)
│   ├── models.py      ฐานข้อมูล SQLite: members, matches, price_boards, bets, txns, results, keywords
│   ├── line_api.py    LINE Messaging API: reply/push, โหลดสลิป
│   ├── web.py         FastAPI: POST /webhook (LINE) + GET / (พอร์ทแอดมิน) + GET/POST /api/*
│   └── seed.py        โหลดคีย์ลัด 206 รายการจาก all_details.json ลงฐานข้อมูล
├── webui/index.html   หน้าพอร์ทแอดมิน (SPA)
├── tests/test_calc.py ทดสอบเครื่องคำนวณ (12 tests ผ่านหมด)
├── config.example.yaml ตัวอย่างการตั้งค่า
├── run.py             รันบอท (uvicorn)
└── requirements.txt
```

## กติกาการแทง (ตาม กก3)

| พิมพ์ | ผลลัพธ์ |
|---|---|
| `ด500` / `แดง 500` / `✅,ด500` | แทงแดง 500 → **ติด** |
| `ง500` / `ง 500` | แทงเงิน 500 → **ติด** |
| `ง500ด` / `ด1000ง` / `ด1000นะ` | **ไม่ติด** (ไม่ใช่การเดิมพัน) |
| `งด` / `ดง` | **ไม่ติด** |
| `c` | ดูเครดิตคงเหลือ |
| `cc` | ดูบิลล่าสุด 5 รายการ + เครดิต |
| `ยก` | ยกเลิกบิลล่าสุด (คืนยอด) |

การตรวจยอด: บิลจะติดได้ไม่เกิน **เครดิตคงเหลือ** และไม่เกิน **ป้ายรับคงเหลือ** ของมุมนั้น ถ้าป้ายรับหมดจะตอบ "ติดเต็มจำนวน"

## การติดตั้งและรัน (self-host)

```bash
# 1) ติดตั้ง dependencies
pip3 install -r requirements.txt

# 2) โหลดคีย์ลัด 206 รายการลงฐานข้อมูล
python3 -m app.seed

# 3) ตั้งค่า env (หรือ copy config.example.yaml → config.yaml)
export LINE_CHANNEL_ACCESS_TOKEN="..."
export LINE_CHANNEL_SECRET="..."
export LINE_ADMIN_IDS="Uxxxxxxxx...,Uyyyyyyyy..."
export ADMIN_TOKEN="รหัสลับของคุณ"

# 4) รัน
python3 run.py          # http://0.0.0.0:8000
```

## ตั้งค่า LINE Webhook

1. ไปที่ [LINE Developers Console](https://developers.line.biz/) → เลือก channel ของคุณ (Messaging API)
2. ในแท็บ Messaging API → Webhook URL ใส่ `https://โดเมนของคุณ/webhook` (ต้องเป็น HTTPS; ใช้ ngrok ตอน dev ได้: `ngrok http 8000`)
3. เปิดใช้ Webhook และปิด "Use webhook" ในห้องแชท (bot จะรับทุกอย่าง)
4. เอา Channel Access Token ใส่ใน `LINE_CHANNEL_ACCESS_TOKEN`
5. หา LINE User ID ของตัวคุณเอง (พิมพ์อะไรก็ได้ในแชท แล้วดูใน log ของบอท — จะมี `source.userId` ปรากฏใน `data/` หรือเปิดโหมด log) แล้วใส่ใน `LINE_ADMIN_IDS`

## คีย์ลัดแอดมิน

| คำสั่ง | ความหมาย |
|---|---|
| พิมพ์ราคาเหมือนป้าย (เช่น `กลางอากาศ ⏎ 🔴ด52 ง53 ⏎ รับ4000`) | เปิดราคา/เปิดคู่ |
| `จ` | ประกาศผล: แดงชนะ → คำนวณบิลอัตโนมัติ |
| `จง` | น้ำเงินชนะ |
| `เสมอ` | เสมอ → คืนยอดทุกบิล |
| `ยก` / `ยุติ` / `x` `xx` `xxx` | ยกเลิกคู่ → คืนยอด |
| `ฝากU000... 1000` | บันทึกฝากรับ (เครดิต +1000) |
| `ถอนU000... 500` | อนุมัติถอน (เครดิต −500) |
| `เติมU000... 2000` | เติมเครดิตให้สมาชิกใหม่/เก่า |

## พอร์ทแอดมินเว็บ

เปิด `http://โดเมนของคุณ/` (token: `ADMIN_TOKEN`) มี 5 แท็บ:

1. **คู่แข่งขัน** — เปิดคู่ใหม่, ประกาศผล (แดงชนะ/เงินชนะ/เสมอ/ยกเลิกคู่) พร้อมคำนวณบิลอัตโนมัติ
2. **ยอดรวมเจ้ามือ** — ดูยอดแทงจริงต่อคู่/ต่อมุม + "เสียสูงสุด" (ความเสี่ยงเจ้ามือ = ยอดติด × เรท)
3. **สมาชิก/เครดิต** — ฝาก/ถอน/เติมเครดิตด้วย LINE User ID
4. **บิลแทง** — ตารางบิลทั้งหมด พร้อมสถานะ (ติด/ไม่ติด/ยกเลิก)
5. **คีย์ลัด 206** — ค้นหาคีย์ลัดและคำตอบทั้งหมดที่โหลดจาก LINE OA เดิม

## การดีพลอยบนเซิร์ฟเวอร์จริง

```bash
# ตัวอย่างด้วย systemd (Ubuntu)
sudo pip3 install -r requirements.txt gunicorn
sudo gunicorn app.web:app -b 0.0.0.0:8000 -w 4 --chdir /path/to/muaythai_bot &
# หรือใช้ nginx + supervisor / docker ตามความถนัด
```

แนะนำใช้ reverse proxy (nginx/caddy) ครอบด้วย HTTPS ก่อนตั้ง Webhook URL ของ LINE

## หมายเหตุ

- ฐานข้อมูล SQLite อยู่ที่ `data/muaythai.db` — ควรถือ backup ไฟล์นี้เป็นประจำ
- ภาพ/วิดีโอ 7 ไฟล์ (เสมอ, ชิงดำ, งช, ดช, กก5, มป, บช) ต้องอัปโหลดขึ้น host ของตัวเอง แล้วใส่ URL ใน `config.yaml` → `media_urls` จึงจะส่งรูปใน LINE ได้
- การเปลี่ยนผล/แก้ไขบิลย้อนหลัง ทำผ่านพอร์ทเว็บหรือ `set_result()` + `settle_match()` ใน `models.py`
